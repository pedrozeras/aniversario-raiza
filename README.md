# Aniversário da Raiza Alves

Versão web responsiva da homenagem, preparada para celular e computador.

## Arquivos
- `mobile/index.html`: página da homenagem.
- `mobile/style.css`: layout responsivo e animações.
- `mobile/script.js`: controles das velas e da música.

## Executar
Abra `mobile/index.html` em um navegador. Para publicar com GitHub Pages, configure a pasta raiz do site para `/mobile` (ou mova os arquivos de `mobile/` para a raiz).

## Áudio
O player espera o arquivo `mobile/musica.mp3`. O arquivo de áudio original ainda não foi enviado ao repositório; adicione-o nesse caminho para habilitar a música. O navegador só permite iniciar a reprodução após uma interação do visitante.
